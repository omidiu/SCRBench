# Dataset access

Both datasets are publicly available on Hugging Face.

| Artifact | Where to start |
| --- | --- |
| Full corpus and evaluation subsets | [SCRBench dataset card](https://huggingface.co/datasets/omidiu/SCRBench) for loading commands and split names. [Dataset details](https://huggingface.co/datasets/omidiu/SCRBench/blob/main/docs/benchmark_details.md) for the schema, transformations, and how the subsets relate. |
| Saved model responses | [SCRBench-results](https://huggingface.co/datasets/omidiu/SCRBench-results) for the response archive and checksum manifest. [Archive details](https://huggingface.co/datasets/omidiu/SCRBench-results/blob/main/docs/results_details.md) for the run inventory and CSV columns. |

To download and score the saved responses, follow [Reproduce the paper results](reproducing_results.md).
